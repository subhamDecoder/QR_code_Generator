# QR Code Generator 🔳

A simple web application to generate QR codes from text or URLs using **HTML**, **CSS**, and **JavaScript**. Users can enter any text or URL, and the app will generate a QR code instantly.

---

## ✨ Features

- ✅ Generate QR codes from any text or URL
- 🎨 Clean and simple UI
- ⚡ Instant QR code generation
- 📱 Fully responsive for mobile and desktop
- 🧠 No backend required — pure frontend app

---

## 🚀 Technologies Used

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
- [GoQR API](https://goqr.me/api/) *(if used in JS for QR generation)*
